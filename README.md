# sue-keyboard

오픈소스 [천지in](https://github.com/oesoll/cheonjiin)을 바탕으로 만든 개인용 iOS 천지인 키보드입니다. 홈 화면과 키보드 목록에는 **이진수키**로 표시됩니다.

ㅣ ㆍ ㅡ 세 획이면 충분해요. 이진수키는 군더더기 없이 가볍게 만든 천지인 키보드예요.

- 광고, 추적, 구독이 없어요.
- 네트워크 코드가 없어요. 키보드는 입력한 글자를 어디로도 보내지 않아요.
- '전체 접근 허용' 없이도 기본 설정으로 모든 입력 기능이 동작해요. 전체 접근은 진동·키 소리와 앱에서 바꾼 설정을 키보드에 전하는 데 쓰여요.

## 입력 방법

| | |
|---|---|
| 모음 | ㅣ ㆍ ㅡ 세 획을 이어 누릅니다. ㅣㆍ = ㅏ, ㆍㅣ = ㅓ, ㆍㅡ = ㅗ, ㅡㆍ = ㅜ, ㅡㆍㆍㅣ = ㅝ |
| 자음 | 같은 키를 이어 누르면 ㄱ → ㅋ → ㄲ |
| 간격 | 천지인에서 조합 중이면 조합만 끝내고(안녕: ㄴ, 간격, ㄴ), 아니면 띄어씁니다. 두벌식에서는 바로 띄어씁니다. |
| ⌫ | 누른 순서를 거꾸로 되감습니다. 가기 → 각 → 가. 길게 누르면 단어째 지웁니다 |
| .,?! | 연타로 . , ? ! 를 오갑니다 |
| 🌐 | 탭: 설정한 언어 순서대로(천지인·두벌식·English), 길게: 다음 키보드 |
| 123 | 숫자·기호 두 쪽(1/2, 2/2) |
| 길게 누르기 | 같은 글자를 계속 입력(ㅋㅋㅋ, ㅠㅠㅠ) |
| 천지인 자음 키 밀기 | 왼쪽으로 밀면 키에 적힌 두 번째 자음(예: ㄱ에서 ㅋ, ㄴ에서 ㄹ)을 입력합니다. ㄱ·ㄷ·ㅂ·ㅅ·ㅈ을 오른쪽으로 밀면 각각 ㄲ·ㄸ·ㅃ·ㅆ·ㅉ을 입력합니다. |
| 천지인 모음 키 밀기 | ㅣ 키를 왼쪽으로 밀면 ㅓ, 오른쪽으로 밀면 ㅏ를 입력합니다. ㅡ 키를 위로 밀면 ㅗ, 아래로 밀면 ㅜ를 입력합니다. |

가로 화면에서는 한글이 두벌식으로 바뀝니다.

앱에서 언어 목록과 순서, 가로 화면 두벌식, 길게 누르기(켜기·시작 시간·빠르기), 진동(켜기·세기), 키 소리, 키 높이(세로·가로)를 바꿀 수 있습니다.

## 구조

- `Core/` — 천지인 조합 엔진(`CheonjiinEngine`). UIKit에 의존하지 않는 Swift 패키지로, `swift test`로 조합 규칙 전체를 검증합니다.
- `Keyboard/` — 키보드 확장. SwiftUI 없이 UIKit 뷰 하나가 터치를 직접 받아 그립니다.
- `App/` — 키보드를 켜는 방법을 안내하는 컨테이너 앱.

## 직접 빌드하기

필요한 것: Xcode 16 이상, [XcodeGen](https://github.com/yonaskolb/XcodeGen)

```sh
cp Config/Local.xcconfig.example Config/Local.xcconfig   # 자기 팀 ID와 번들 ID 접두사를 넣는다
xcodegen generate
open sue-keyboard.xcodeproj
```

조합 엔진 테스트:

```sh
cd Core && swift test
```

## GitHub Actions에서 IPA 빌드하기

GitHub의 Actions 탭에서 **Build unsigned IPA → Run workflow**를 선택합니다. 빌드가 완료되면 실행 결과의 **Artifacts → sue-keyboard-unsigned**에서 ZIP을 내려받으세요. ZIP 안에 앱과 키보드 확장을 포함한 `sue-keyboard-unsigned.ipa`가 들어 있습니다. iPhone에 설치하려면 앱과 키보드 확장에 기기용 서명을 적용해야 합니다.

## 개인정보처리방침

이진수키는 어떤 개인정보도 수집하거나 저장하거나 전송하지 않습니다.

- 키보드와 앱 모두 네트워크를 사용하지 않습니다.
- 입력한 글자는 기기 안에서 조합에만 쓰이고, 저장되거나 외부로 나가지 않습니다.
- 광고, 분석, 추적 도구를 포함하지 않습니다.
- '전체 접근 허용'은 진동·키 소리와, 앱에서 고른 설정을 키보드에 전하는 데만 쓰입니다. 꺼도 기본 설정으로 모든 입력 기능이 동작합니다.
- 설정은 기기 안의 App Group 저장소에만 저장됩니다.
